# الموقع الشخصي الأكاديمي والبحثي للدكتور علاء أبو زعيتر
## Dr. Eng. Alaa A. AbuZaiter — Academic & Research Portfolio

موقع أكاديمي شخصي مستقل متعدد الصفحات، مبني باستخدام **Next.js 15 (App Router)** و **TypeScript** و **Tailwind CSS**، ثنائي اللغة بالكامل (العربية بالاتجاه RTL والإنجليزية بالاتجاه LTR).

## 2. الهيكل المعماري والصفحات (Multi-page Architecture)

الموقع ليس صفحة هبوط واحدة، بل موقع متكامل يضم مسارات مستقلة:

1. **الرئيسية (`/[locale]`):** الهوية الأكاديمية والبحثية، شريط الحقائق الموثقة، ركائز التخصص، أبحاث مختارة، والمدخل للقيادة والتدريس.
2. **نبذة عن الدكتور (`/[locale]/about`):** السيرة المهنية والفلسفة الأكاديمية واللغات مع حجب البيانات الحساسة.
3. **المسيرة الأكاديمية (`/[locale]/academic-journey`):** خط زمني مزدوج يفصل التعليم العالي (دكتوراه UTM، ماجستير UTM، بكالوريوس الأزهر) عن الخبرات الوظيفية.
4. **القيادة والمناصب (`/[locale]/leadership`):** عقد زمنية للمناصب الإدارية مع تخصيص مساحات للمسؤوليات والإنجازات الموسومة بـ `[قيد التوثيق الرسمي]`.
5. **مجالات البحث (`/[locale]/research`):** تفصيل المحاور الستة في MEMS و SMA والروبوتات والمناولات الدقيقة والتحكم.
6. **مكتبة الأبحاث (`/[locale]/publications`):** كونسول بحث فوري، تصنيف وفلاتر (11 مجلة محكمة، 6 مؤتمرات، فصلان في كتب)، مستخلصات موسعة، ودرج نسخ الاقتباس (BibTeX / APA).
7. **المؤتمرات العلمية (`/[locale]/conferences`):** توثيق أوراق وقائع المؤتمرات المنشورة مع فصلها التام عن الحضور الميداني والإلقاء.
8. **المساقات الدراسية (`/[locale]/teaching`):** مصفوفة المساقات الـ 14 بالأسماء الأصلية الحرفية الواردة في السيرة الذاتية.
9. **الإشراف الطلابي (`/[locale]/supervision`):** إطار مجالات الإشراف الأكاديمي دون اختلاق أسماء طلبة أو مشاريع.
10. **التطوير المهني (`/[locale]/activities`):** ورش العمل المتخصصة وتصنيع MEMS في الغرف النقية.
11. **الجوائز والتكريمات (`/[locale]/awards`):** الجوائز الثلاث الموثقة في السيرة.
12. **السيرة الذاتية (`/[locale]/cv`):** ملخص منظم مع إتاحة تنزيل النسخة المنقحة رقمياً.
13. **التواصل الأكاديمي (`/[locale]/contact`):** البريد المؤسسي الرسمي وضمان حماية الخصوصية بعدم استخدام نماذج تتبع.
14. **المسارات المعلقة المخفية:** `/community` و `/media` مجهزة هيكلياً ومحجوبة تماماً عن شريط التنقل لعدم وجود بيانات معتمدة.

## 3. التشغيل والتطوير المحلي

```bash
# تثبيت الحزم (تم مسبقاً)
npm install

# تشغيل خادم التطوير المحلي
npm run dev

# فحص أنواع TypeScript
npx tsc --noEmit

# بناء النسخة الإنتاجية
npm run build

# تشغيل النسخة الإنتاجية
npm run start
```

## 4. ضوابط حماية الخصوصية ودقة المحتوى

1. **حظر تام لنشر البيانات الحساسة:** تاريخ الميلاد، العنوان السكني، ورقم الهاتف الشخصي محظورة ومحجوبة تماماً عن كود الموقع وصفحاته.
2. **استبعاد بحث كوفيد (JESTEC 2022):** مستبعد بالكامل من قائمة المنشورات لعدم ورود اسم الدكتور ضمن قائمة مؤلفيه المطبوعة بالسيرة.
3. **عدم اختلاق البيانات:** لا توجد إحصائيات وهمية، ولا عدادات استشهاد عشوائية، ولا مشاريع طلبة مجهولة، ولا ادعاءات متحدث رئيسي دون توثيق.
