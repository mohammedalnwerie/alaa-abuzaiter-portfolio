## 1. المعمارية التقنية والتصميمية المعتمدة

* **إطار العمل الأساسي:** Next.js (App Router) مع TypeScript.
* **إطار التنسيق البصري:** Tailwind CSS مع نظام Design Tokens أكاديمي مخصص.
* **المكتبات المساندة:** Lucide React للأيقونات الأكاديمية والهندسية الخفيفة.
* **دعم اللغات والاتجاهات:** ثنائية لغة متأصلة (`ar` بالاتجاه RTL و `en` بالاتجاه LTR) مع محاذاة تلقائية وحفظ مسار الصفحة عند التبديل.
* **إدارة المحتوى:** طبقة بيانات محلية صارمة النوعية (`src/content/`) منفصلة تماماً عن العرض وموثقة في `CONTENT_AUDIT.md`.
* **مستوى حماية الخصوصية:** حجب كامل وتام لتاريخ الميلاد وعنوان السكن ورقم الهاتف الشخصي.

## 3. مراحل التنفيذ التفصيلية

### المرحلة 1: تهيئة المشروع ونظام التصميم (Project Setup & Design Tokens) — [مكتملة]
- تهيئة بيئة Next.js App Router مع TypeScript و Tailwind CSS.
- تحديد ألوان الهوية: Deep Navy (`#14243A`)، Warm Off-white (`#F7F8FA`)، Muted Teal (`#2D9C98`).
- ضبط خطوط `IBM Plex Sans Arabic` و `Inter`.
- إنشاء بنية التوجيه ثنائي اللغة `[locale]`.

### المرحلة 2: تطوير الصفحة الرئيسية (Homepage Development) — [مكتملة]
- قسم الهيرو الأكاديمي مع شارات الرتبة والمنصب والكلية المحدثة.
- إطار الصورة الوقورة مع علامات الزوايا الهندسية لشرائح MEMS.
- شريط الحقائق الأكاديمية الموثقة الخالي من العدادات الرقمية الوهمية.
- شبكة ركائز التخصص مع الأيقونات المجردة.
- أحدث 3 أبحاث محكمة مختارة مع روابط المعرف الرقمي DOI.
- بطاقات الاستعراض المزدوج للقيادة والتدريس.

### المرحلة 3: مكتبة الأبحاث التفاعلية (Research Library) — [مكتملة]
- كونسول البحث النصي الفوري بالكلمة، اسم المؤلف، المجلة، أو المعرف الرقمي.
- فلاتر التبويب: المجلات المحكمة (11)، أوراق المؤتمرات (6)، فصول الكتب (2).
- تمييز اسم الدكتور علاء أبو زعيتر بين المؤلفين.
- أكورديون عرض المستخلص العلمي.
- نافذة نسخ الاقتباس الأكاديمي المباشر بصيغتي BibTeX و APA.
- استبعاد دائم لبحث كوفيد 2022 لغياب اسم الدكتور في السيرة.

### المرحلة 4: المسيرة الأكاديمية والقيادة (Academic Journey & Leadership) — [مكتملة]
- صفحة المسيرة الأكاديمية بخط زمني يفصل التعليم العالي عن المسار الوظيفي.
- صفحة القيادة المستقلة مع عقد زمنية للمناصب الإدارية بجامعة فلسطين.
- حقول محددة للمسؤوليات والإنجازات موسومة بعلامة `[قيد التوثيق الرسمي]`.
- توثيق عضوية مجلس البحث العلمي وفق صياغة السيرة المعتمدة.

### المرحلة 5: التدريس والمقررات الجامعية (Teaching & Courses) — [مكتملة]
- الحفاظ على الأسماء الأصلية الحرفية لـ 14 مساقاً تخصصياً.
- تصنيف المساقات وفق 6 مجالات هندسية وأكاديمية.
- إيضاح البرمجيات والأدوات المساندة لكل مساق (MATLAB, SolidWorks, Proteus, ANSYS).
- صفحة الإشراف الطلابي المؤطرة دون اختلاق أسماء طلبة أو مشاريع.

### المرحلة 6: الصفحات المساندة والمسارات المعلقة (Remaining Pages & Scaffolds) — [مكتملة]
- صفحات النبذة (`/about`)، المحاور البحثية (`/research`)، المؤتمرات (`/conferences`)، الأنشطة (`/activities`)، الجوائز (`/awards`)، السيرة الذاتية (`/cv`)، والتواصل المؤسسي (`/contact`).
- مسارات العمل المجتمعي (`/community`) والإعلام (`/media`) مبنية برمجياً ومحجوبة تماماً عن قوائم التنقل العامة.

### المرحلة 7: فحص التكامل والإتاحة والتجاوب (Testing & Delivery) — [قيد المراجعة]
- فحص خلو الكود من أخطاء TypeScript: تم بنجاح (`tsc --noEmit` code 0).
- تجربة اتجاه RTL و LTR على مختلف الشاشات.
- التحقق من تباين الألوان وملاءمة لوحة المفاتيح.
