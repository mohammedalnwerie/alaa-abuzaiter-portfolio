# معرض الصور — طريقة الإضافة / Adding photos to the gallery

الصفحة: `/ar/gallery` و `/en/gallery`. تظهر في القائمة (تحت «الأنشطة») وفي الفوتر **فقط** عند وجود صورة معتمدة واحدة على الأقل. قبل ذلك تعرض الصفحة قائمة المتطلبات، وهي محجوبة عن محركات البحث وغير مرتبطة بأي رابط.

## القواعد
- صور حقيقية فقط. لا صور مولّدة بالذكاء الاصطناعي ولا صور أرشيفية لأشخاص آخرين.
- لا تُضبط `approved: true` إلا بعد موافقة الدكتور على الصورة **وموافقة كل شخص يمكن التعرّف عليه فيها**.
- وصف الصورة `alt` إلزامي بالعربية والإنجليزية: ماذا تُظهر الصورة، في سطر واحد.
- لا تُستنتج تواريخ أو أماكن أو أسماء غير مؤكدة.

## الخطوات
1. ضع الملف في `public/gallery/`. اسم مقترح: `2015-utm-mems-lab.jpg` (حروف إنجليزية صغيرة وشرطات). يكفي عرض 2000 بكسل تقريباً؛ الموقع يولّد النسخ المصغرة تلقائياً.
2. أضف بنداً إلى `galleryPhotos` في `src/content/gallery.ts`:

```ts
{
  id: "2015-utm-mems-lab",
  src: "/gallery/2015-utm-mems-lab.jpg",
  alt: { en: "Dr. AbuZaiter at a probe station in the UTM MEMS Laboratory", ar: "د. أبو زعيتر عند محطة القياس في مختبر MEMS بجامعة تكنولوجي ماليزيا" },
  caption: { en: "MEMS Laboratory, UTM", ar: "مختبر MEMS، جامعة تكنولوجي ماليزيا" },   // اختياري
  date: "2015",                                                                   // "YYYY" أو "YYYY-MM" — اختياري
  place: { en: "Johor, Malaysia", ar: "جوهور، ماليزيا" },                          // اختياري
  category: "lab",          // lab | conference | university | teaching | event | other
  credit: "Name",           // اختياري
  approved: true,
},
```

3. أعد البناء والتشغيل: `npm run build` ثم `npm run start`.

الترتيب زمني تلقائياً حسب `date`، والصور بلا تاريخ تأتي في النهاية. أزرار التصفية تظهر للفئات الموجودة فقط.

## ما يطلبه الموقع لكل صورة (للإرسال إلى الدكتور)
ملف الصورة بدقته الكاملة · ماذا تُظهر (سطر بالعربية والإنجليزية) · التاريخ · المكان أو المناسبة · الفئة · اسم المصوّر إن رُغب بذكره · موافقة الأشخاص الظاهرين.
