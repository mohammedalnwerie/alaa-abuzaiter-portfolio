## 1. ملخص المشروع

إنشاء موقع شخصي مستقل واحترافي للدكتور المهندس **علاء عبدالله حسن أبو زعيتر**، يعرض هويته الأكاديمية والبحثية والقيادية بصورة راقية وسهلة التصفح، ويكون مرجعاً رقمياً موثوقاً للباحثين والطلبة والزملاء والمؤسسات الأكاديمية.

الموقع ليس موقعاً للجامعة، وليس صفحة إدارية للكلية، ولا مجرد نسخة إلكترونية من السيرة الذاتية. هو موقع شخصي يعكس ثلاث هويات مترابطة:

1. **Academic Identity:** المؤهلات، المسيرة الأكاديمية، التدريس والإشراف.
2. **Research Identity:** مجالات البحث، المنشورات، المشاريع والتعاون البحثي.
3. **Leadership Identity:** الخبرة القيادية والرؤية والمساهمات الأكاديمية.

### الهدف الأساسي

أن يستطيع باحث أو أكاديمي يزور الموقع للمرة الأولى فهم خلفية الدكتور، تخصصه البحثي، أبرز أبحاثه، ومسيرته القيادية خلال دقيقة تقريباً، ثم الوصول بسهولة إلى التفاصيل والمصادر الأكاديمية الأصلية.

## 6. تجربة المستخدم ومتطلبات التصميم

- تصميم Responsive حقيقي يبدأ من الهاتف ثم يتوسع للشاشات الكبيرة.
- واجهة إنجليزية LTR وعربية RTL حقيقية، وليست مجرد محاذاة نص إلى اليمين.
- زر تبديل اللغة ظاهر في رأس الصفحة.
- قائمة هاتف سهلة الاستخدام.
- Header ثابت أو شبه ثابت دون أن يغطي المحتوى.
- Footer يحتوي الاسم، الصفة المهنية، الروابط، وحقوق النشر.
- روابط خارجية تفتح بطريقة مناسبة، مع توضيح أنها تنقل الزائر إلى مصدر خارجي.
- حالات Hover وFocus واضحة.
- دعم لوحة المفاتيح وقارئات الشاشة.
- مراعاة إعداد `prefers-reduced-motion`.
- تباين ألوان مناسب وحجم خط مريح.
- لا تضع نصوصاً طويلة داخل بطاقات صغيرة.
- لا تستخدم إحصائيات عدّاد متحركة إذا كانت الأرقام غير مؤكدة.
- لا تستخدم Slider تلقائياً أو فيديو Hero ثقيل.

## 7. التقنية المقترحة

### الاختيار الأساسي

- **Framework:** Next.js باستخدام App Router.
- **Language:** TypeScript.
- **Styling:** Tailwind CSS، مع CSS مخصص للتفاصيل التي تحتاج هوية فريدة.
- **Motion:** CSS transitions أولاً؛ يمكن استخدام Motion for React للحركات الضرورية فقط.
- **Icons:** Lucide أو SVG icons بسيطة.
- **Content:** ملفات بيانات محلية منظمة TypeScript/JSON/MDX، لتسهيل تحديث المحتوى دون Backend.
- **Deployment:** Vercel، أو استضافة متوافقة مع Next.js بعد تحديد النطاق.
